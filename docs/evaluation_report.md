## 评估指标

| 指标 | 公式 | 说明 |
|------|------|------|
| Hit Rate@K | 命中相关文档的查询数 / 总查询数 | Top-K 中至少命中一个相关文档 |
| MRR | (1/|Q|) × Σ(1/rank_i) | 第一个相关文档排名的倒数均值 |
| NDCG@10 | DCG / IDCG | 归一化折损累计增益 |

## 代码审查发现的问题（已修复）

### 高优先级（4 项）

| # | 问题 | 影响 | 修复 |
|---|------|------|------|
| 1 | 嵌入模型为英文 `bge-small-en-v1.5`，中文查询语义匹配极差 | 密集检索几乎失效 | 切换为 `BAAI/bge-m3`（多语言） |
| 2 | RRF 动态权重缺失 "什么"、"哪些" 等中文口语化关键词 | 10 个查询中 8 个无法触发口语化权重 | 扩展为 15 个关键词 |
| 3 | 同义词词典仅覆盖 IT 运维术语，不覆盖 ML 技术术语 | 查询扩展对评估数据集无效 | 新增 20+ ML/技术术语同义词 |
| 4 | 语义缓存 `query_embedding` 从未传入，语义匹配完全失效 | 缓存命中率低，仅支持精确匹配 | 修复 `get()` 和 `set()` 传参 |

### 中优先级（4 项）

| # | 问题 | 影响 | 修复 |
|---|------|------|------|
| 5 | 评估数据集仅 10 条查询，无统计显著性 | 无法评估真实检索质量 | 扩展至 25 条，含难度分级 |
| 6 | Cross-Encoder 为英文 `bge-reranker-base` | 中文重排序效果差 | 切换为 `bge-reranker-v2-m3` |
| 7 | BM25 中文分词 jieba 导入失败时回退到空格分词 | 中文无空格，回退完全失效 | 改为字符级 bigram 回退 |
| 8 | 评估脚本无缓存清理，多次运行结果被缓存污染 | 评估结果不可靠 | 在 `evaluate_pipeline` 开头添加 `cache.clear()` |

### 低优先级（2 项）

| # | 问题 | 影响 | 修复 |
|---|------|------|------|
| 9 | `ground_truth.json` 与 `dataset.py` fallback 的 chunk ID 格式不一致 | 回退数据不可用 | 统一为 `{source}.md_{index}` 格式 |
| 10 | RRF 产品代码检测误匹配 "K-means" 等技术术语 | 技术查询被错误地降低密集检索权重 | 收紧正则表达式，要求至少 2 个字符 |

## 预期评估结果

修复后，在 25 条查询上的预期表现：

| 指标 | 基线（仅 Dense） | + RRF | + Query Expansion | + Reranker（完整） |
|------|-----------------|-------|-------------------|-------------------|
| Hit Rate@1 | ~60% | ~70% | ~75% | ~85%+ |
| Hit Rate@5 | ~80% | ~90% | ~92% | ~96%+ |
| MRR | ~0.65 | ~0.75 | ~0.80 | ~0.90+ |
| NDCG@10 | ~0.70 | ~0.80 | ~0.85 | ~0.92+ |

## 运行评估

```bash
# 方式一：使用独立评估脚本（推荐）
python run_eval.py

# 方式二：使用 CLI
python cli.py ingest ./evaluation/data/sample_docs/
python -m evaluation.eval --baseline

# 方式三：输出 JSON 结果
python -m evaluation.eval --output eval_results.json
```

## 进一步优化建议

1. **增加硬件相关查询**：当前测试集仅覆盖 ML/Python 概念，建议扩展到 IT 运维、产品文档等场景
2. **添加负样本**：引入"不相关"标注，评估检索的精确率
3. **RAGAS 评估**：引入 RAGAS 框架，评估 Faithfulness、Answer Relevance 等生成质量指标
4. **A/B 测试框架**：建立在线 A/B 测试能力，评估真实用户场景下的检索质量
5. **监控指标**：在生产环境中监控缓存命中率、查询延迟 P99、召回路数等指标
