# 回归问题详解

回归问题是监督学习中预测连续数值的任务类型。回归分析是统计学和机器学习中最基础的方法之一。

## 回归问题的特点

回归问题有以下特点：
- 输出变量是连续的数值
- 目标是最小化预测值与真实值之间的误差
- 可以使用各种误差度量来评估模型性能

## 常见回归算法

### 线性回归

线性回归是最简单的回归方法，它假设目标变量与特征之间存在线性关系。模型通过最小化残差平方和来拟合数据。

### 多项式回归

多项式回归通过添加特征的高次项来捕捉非线性关系。虽然它仍然是关于参数的线性模型，但可以拟合非线性数据。

### 岭回归和Lasso回归

这两种方法在线性回归的基础上添加了正则化项。岭回归使用L2正则化，Lasso回归使用L1正则化。正则化可以防止过拟合，Lasso还可以实现特征选择。

### 决策树回归

决策树回归与分类决策树类似，但叶节点输出的是连续值而非类别标签。它通过递归划分数据空间来拟合复杂的非线性函数。

## 回归与分类的区别

回归与分类是监督学习中两种基本的问题类型，它们的核心区别在于：
- 分类问题：预测离散的类别标签（如：是/否、猫/狗/鸟）
- 回归问题：预测连续的数值（如：价格、温度、年龄）

选择分类还是回归取决于我们需要预测的目标变量类型。如果目标是离散的类别，使用分类；如果目标是连续的数值，使用回归。
