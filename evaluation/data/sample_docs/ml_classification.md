# 分类问题详解

分类问题是监督学习中的一种基本任务类型。分类问题的目标是将输入数据分配到一个或多个预定义的类别中。

## 分类问题的特点

分类问题有以下特点：
- 输出变量是离散的类别标签
- 每个类别是互斥的（对于多分类问题）
- 模型的输出通常是各类别的概率分布

## 常见分类算法

### 逻辑回归

尽管名称中有"回归"，逻辑回归实际上是一种分类算法。它使用Sigmoid函数将线性输出映射到0到1之间的概率值，适用于二分类问题。

### 决策树

决策树通过递归地划分数据空间来进行分类。每个内部节点表示一个特征测试，每个分支代表测试结果，每个叶节点代表一个类别。

### 随机森林

随机森林是多个决策树的集成，通过投票机制来决定最终分类结果。它能够有效减少过拟合，提高泛化能力。

### 支持向量机（SVM）

SVM通过寻找最大化类别间隔的超平面来进行分类。对于非线性可分的问题，SVM使用核函数将数据映射到高维空间。

## 分类与回归的区别

分类和回归是监督学习的两大核心任务，它们的主要区别在于：
- 输出类型：分类预测离散的类别，回归预测连续的数值
- 评估指标：分类使用准确率、精确率、召回率等，回归使用MSE、MAE等
- 应用场景：分类用于识别、判断等任务，回归用于预测数值

理解分类和回归的区别对于选择合适的算法和评估方法至关重要。
