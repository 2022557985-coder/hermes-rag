# 交叉验证

交叉验证（Cross-Validation）是机器学习和统计学中评估模型性能和泛化能力的重要方法。它通过多次划分训练集和验证集来获得更可靠的模型性能估计。

## 交叉验证的作用

交叉验证的主要作用包括：

### 1. 评估模型的泛化能力

交叉验证通过在不同数据子集上测试模型，能够更准确地估计模型在未见数据上的表现。这避免了单次划分可能带来的偶然性。

### 2. 减少过拟合风险

通过多次训练和验证，交叉验证能够帮助检测模型是否过拟合。如果模型在训练集上表现很好但在验证集上表现较差，说明可能存在过拟合问题。

### 3. 模型选择

交叉验证可以用来比较不同模型的性能，帮助我们选择最优的模型。通过比较多个模型在交叉验证中的平均表现，可以做出更可靠的模型选择决策。

### 4. 超参数调优

交叉验证是超参数调优的核心工具。通过在不同超参数组合上执行交叉验证，找到使模型性能最优的超参数配置。

## 交叉验证的常见类型

- K折交叉验证：将数据分成K份，每次用K-1份训练，1份验证
- 留一交叉验证（LOOCV）：每次只留一个样本作为验证集
- 分层K折交叉验证：保持每折中类别比例与原始数据一致
- 时间序列交叉验证：适用于时间序列数据，保持时间顺序

交叉验证虽然增加了计算开销，但它是确保模型可靠性的重要手段，是机器学习实践中的标准做法。
