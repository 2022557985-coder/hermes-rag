# CNN架构详解

卷积神经网络（Convolutional Neural Network，CNN）是深度学习中最重要和广泛使用的架构之一，特别擅长处理具有网格结构的数据，如图像和视频。

## CNN的核心组件

CNN的架构主要由以下几种层组成：

### 卷积层（Convolutional Layer）

卷积层是CNN的核心。它使用一组可学习的卷积核（滤波器）在输入数据上滑动，执行卷积操作来提取局部特征。每个卷积核负责检测一种特定的特征模式，如边缘、纹理或更高级的语义特征。

卷积层的主要参数包括：
- 卷积核大小（Kernel Size）：通常为3x3或5x5
- 步长（Stride）：卷积核滑动的步长
- 填充（Padding）：在输入边界添加像素以控制输出尺寸
- 通道数：输出特征图的数量

### 池化层（Pooling Layer）

池化层用于降低特征图的空间维度，减少计算量和参数数量，同时保留重要特征。常见的池化操作包括：
- 最大池化（Max Pooling）：取区域内的最大值
- 平均池化（Average Pooling）：取区域内的平均值

### 全连接层（Fully Connected Layer）

全连接层将卷积和池化层提取的特征进行组合，用于最终的分类或回归任务。通常CNN的最后几层是全连接层。

## 经典CNN架构

- LeNet-5：最早的CNN之一，用于手写数字识别
- AlexNet：2012年ImageNet冠军，引入ReLU和Dropout
- VGGNet：使用小卷积核（3x3）堆叠，结构简洁
- ResNet：引入残差连接，解决了深层网络的退化问题
- Inception（GoogLeNet）：使用多尺度卷积核并行处理

CNN架构的设计思想是通过层次化的特征提取，从低级特征（边缘、纹理）逐步构建到高级语义特征（物体部件、完整物体），这是CNN在视觉任务中取得巨大成功的关键。
